Original unmodified data only. Ignored by Git by default.

## Files

- `comtrade_{hs}_imports.csv`: Bilateral import panels (treated + placebo HS codes)
- `comtrade_{hs}_china_exports.csv`: China export time series
- `bloomberg_prices_monthly.csv`: Monthly Bloomberg/Wind prices currently available.
- `eurostat_cn8/`: Original Eurostat product-partner exports; aggregate artifacts are retained only for provenance.
- `geodist/dist_cepii.dta`: Canonical CEPII static GeoDist file.
- `geodist/col_regfile09.dta`: Legacy 1948-2006 annual gravity panel; not the canonical GeoDist input.
- `imports_{hs}/`: Per-reporter raw API downloads (used by download_missing.py)
