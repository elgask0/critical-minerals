# Notes

## Project Use

Core vocabulary source for distinguishing export licensing from bans, quotas, and other export measures.

## Can Support

The classification defines non-tariff measures as policy measures other than ordinary customs tariffs that can affect trade quantities or prices. It provides distinct categories for export-related measures, including prohibitions, quotas, and licensing requirements.

## Cannot Support

Classification source only. It cannot show whether a specific Chinese license binds in observed trade data.
