# Notes

## Project Use

Core context source for the global rise and composition of critical-raw-material export restrictions.

## Can Support

The report documents a long-run increase in export restrictions on critical raw materials and classifies the types of restrictions used by governments. It provides comparative context for why critical minerals are increasingly governed through trade restrictions.

## Cannot Support

Global inventory evidence cannot identify the causal effect of China-specific controls. Use for context and typology.
