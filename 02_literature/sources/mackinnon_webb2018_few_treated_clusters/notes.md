# Notes

## Project Use

Supporting methods source for inference with few treated clusters.

## Can Support

Cluster-robust inference and standard wild cluster bootstrap procedures can fail when the number of treated clusters is very small. The paper develops subcluster wild bootstrap procedures and shows when they perform better.

## Cannot Support

Focused on linear models and cluster structures, not PPML mineral trade panels. Use as an inference caution and robustness reference.
