# Notes

## Project Use

Core methods source for inference when independent policy changes are few.

## Can Support

In many DiD applications, identification comes from a small number of policy changes, while conventional inference assumes many policy-changing groups. The paper develops an inference approach using the distribution from nonchanging groups under point null hypotheses.

## Cannot Support

Classical DiD setup, not a direct PPML DDD estimator. Use for the design-level warning that many observations do not equal many independent shocks.
