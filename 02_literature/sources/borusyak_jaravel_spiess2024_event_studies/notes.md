# Notes

## Project Use

Core methods source for modern event-study diagnostics under staggered adoption.

## Can Support

Conventional regression-based event-study estimators can be inefficient or biased under staggered treatment adoption and heterogeneous treatment effects. The paper proposes an imputation-based framework for robust and efficient event-study estimation.

## Cannot Support

Does not solve all few-shock inference issues by itself and is not specific to PPML trade models.
