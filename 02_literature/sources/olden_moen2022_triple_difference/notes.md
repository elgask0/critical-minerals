# Notes

## Project Use

Core methods source for the triple-difference estimator.

## Can Support

Triple difference is often used by intuition, but its causal interpretation rests on a specific identifying assumption. The estimator can be viewed as the difference between two DiD estimators, but it does not require two independent parallel-trend assumptions; it requires the bias in the two DiD comparisons to be equal.

## Cannot Support

Linear DDD theory, not PPML-specific. Use for identification logic, not as a complete solution to trade-panel inference.
