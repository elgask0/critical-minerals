# Notes

## Project Use

Core methods source for few treated groups with heteroskedasticity.

## Can Support

Standard DiD inference can fail with few treated groups, especially when heteroskedasticity arises from group-size differences. The paper provides an inference method that remains valid under these conditions.

## Cannot Support

Not specific to trade-flow PPML or product-level shocks. Use to motivate conservative inference.
